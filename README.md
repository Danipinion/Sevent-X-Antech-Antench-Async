# Sevent-X-Antech-Antench-Async - Proyek TANDUR 🌱

Repositori resmi tim Sevent-X Antech untuk pengembangan platform **TANDUR**: Platform Rantai Pasok Pertanian Digital.

## Direktori Proyek

Seluruh kode sumber aplikasi, basis data, infrastruktur, dan dokumentasi TANDUR berada di dalam folder [`tandur/`](./tandur):

```bash
cd tandur
make setup
make up
```

Silakan baca [Panduan Lengkap TANDUR](./tandur/README.md) dan [Panduan Setup Tim](./tandur/setup.md).
